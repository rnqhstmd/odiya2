# odiya (어디야)

약속 시간 역산 출발 알림 + 재촉하기(Nudge)가 핵심인 커플/친구 약속 관리 iOS 앱.

## 배경

약속을 잡을 때 이동시간을 수동으로 계산하고, "출발했어?" 카톡을 반복하는 문제가 있다. 이동시간은 교통 상황에 따라 변하고, 출발 타이밍을 직접 판단해야 하므로 지각이 잦다. 재촉하는 쪽도, 재촉받는 쪽도 불편하다.

## 안 하면 어떻게 되는가

매 약속마다 수동으로 이동시간을 검색하고, 알람을 직접 맞추며, "지금 어디야?" 카톡을 보내는 반복이 계속된다.

## 사용자와 규모

- **대상**: 커플, 친한 친구 그룹 (2~6명)
- **플랫폼**: iOS
- **규모**: 초기 소수 사용자 (여자친구와 함께 사용)

## 성공 기준

- **지각률 감소**: 출발 알림으로 제때 출발하는 비율 향상
- **출발 알림 정확도**: 실제 이동시간 대비 오차 5분 이내
- **재촉하기로 카톡 대체**: "출발했어?" 카톡 대신 앱 내 재촉하기 사용

## 현재 상태

설계 중 → UI 프로토타입 완료 (Pencil MCP, 12개 화면)
