## 디자인 원칙

- **부드럽고 신뢰감 있는** — 약속 관리 앱답게 깔끔하면서도 따뜻한 느낌
- **직관적** — 설명 없이도 약속 생성·출발 알림·재촉하기 흐름을 파악 가능
- **iOS 네이티브** — HIG(Human Interface Guidelines) 준수, SwiftUI 기본 컴포넌트 활용
- **오디(보라) 아이덴티티** — 앱 이름 "오디야"의 오디(뽕나무 열매) 색에서 파생한 보라 계열 통일

## 앱 아이콘

> **미정** — 아이콘 확정 시 이 섹션을 업데이트한다.

| 항목 | 상태 |
|------|------|
| 앱 아이콘 (1024x1024) | ⬜ 미정 |
| 앱 아이콘 배경색 | 오디 보라 계열 권장 (`#5B3A8C` ~ `#8B5FBF`) |
| 로그인 화면 로고 | ⬜ 미정 (아이콘 확정 전까지 SF Symbol 플레이스홀더 사용) |
| 탭바·내비게이션 로고 | 사용하지 않음 (텍스트 타이틀) |

### 아이콘 적용 위치

아이콘이 확정되면 아래 위치에 반영한다:

1. **iOS 앱 아이콘** — Assets.xcassets/AppIcon
2. **로그인 화면 중앙 로고** — 현재 SF Symbol 플레이스홀더를 실제 이미지로 교체
3. **스플래시(Launch Screen)** — 오디 보라 배경 + 중앙 앱 아이콘
4. **카카오톡 공유 메시지 썸네일** — 약속 초대·친구 요청 링크에 포함

### 기능별 컬러

| 역할 | 값 | 설명 |
|------|----|------|
| Primary | `#5B3A8C` | 메인 CTA 버튼, 탭바 선택, 강조 |
| Nudge (재촉) | `#D94F8A` | 재촉하기 버튼 전용. 보라에서 핑크 방향으로 이동한 색 |
| Background | 시스템 기본 | iOS 라이트/다크 모드 자동 대응 |
| Surface | 시스템 기본 | 카드·시트 배경 |
| Text Primary | 시스템 기본 | 본문 텍스트 |
| Text Secondary | 시스템 기본 | 보조 텍스트, 플레이스홀더 |

## 주요 화면 레이아웃

### 로그인

- 중앙: 앱 로고 (아이콘 미정 시 SF Symbol 플레이스홀더)
- 중앙: "오디야" 텍스트
- 하단: 카카오 로그인 버튼 (`#FEE500` 배경, 검정 텍스트)

### 내 약속 (메인)

- 상단: "내 약속" 타이틀 + 프로필 아이콘
- 세그먼트: [다가오는 약속] [지난 약속]
- **임박한 약속 카드 (강조)**
  - 배경: Odiya-100 (`#F0E6F7`)
  - 약속명, 장소, 시간, 참여자 프로필 스택
  - 이동수단 아이콘 + 소요시간
  - 출발 카운트다운 타이머 (실시간)
  - 재촉 버튼 (Nudge 컬러 `#D94F8A`, 30분 전 활성화)
- 일반 약속 카드: 컴팩트 (약속명, 장소, 시간, 상태 배지)
- 빈 상태: 아이콘 + 안내 문구 + "약속 만들기" CTA 버튼

### 캘린더

- 상단: 월/연 표시 + [오늘] 버튼 + [월|주] 토글
- 월간 뷰: 그리드 + 약속 있는 날짜에 태그 색상 도트 (최대 3개, 초과 시 `+N`)
- 주간 뷰: 타임라인 + 약속 시간 블록 (태그 색상 배경)
- 하단: 선택된 날짜의 약속 리스트
- 빈 날짜 탭 → 해당 날짜로 약속 생성 진입

### 친구 목록

- 상단: "친구" 타이틀 + toolbar [+] 🔔 👤
- 검색 바
- 태그 필터 칩: `[●전체] [●연인] [●친구] [●가족] [●직장]...`
- 친구 행: 색상 도트 + 프로필 이미지 + 닉네임
- 컨텍스트 메뉴 (`···`): 태그 변경, 친구 끊기 (=차단)

### 설정

- 출발지 관리: 집/회사/기타 + 추가
- 태그 관리: 태그 목록 + 색상 도트 + 추가
- 로그아웃 / 회원 탈퇴
- (프로필은 👤 시트 → 내 프로필로 이동)

### 알림 목록 (🔔 시트)

- 푸시 알림 기록 목록
- 친구 요청: 수락/거절 버튼 인라인
- 약속 초대: 탭 → 약속 상세
- 출발 알림, 재촉 알림
- 읽지 않은 알림 강조 (Odiya-50 배경)

### 내 정보/설정 (👤 시트)

- 프로필 이미지 + 닉네임
- 내 프로필 → ProfileView
- 설정 → SettingsView
- 로그아웃 (Alert 확인/취소)

## UX 패턴

### 재촉하기 UX

- **Haptic Feedback**: 재촉 버튼 탭 시 `.impact(.medium)` 진동
- **Bounce 애니메이션**: 버튼 탭 시 scale down → up 바운스 효과
- 쿨다운 중: 버튼 비활성화 + 원형 프로그레스로 남은 시간 표시
- 재촉 전송 성공: 짧은 체크마크 애니메이션
- 버튼 컬러: Nudge `#D94F8A`

### 약속 생성 — 스텝 위저드

입력 항목이 많으므로 단계별로 나눈다.

```
스텝 1: 약속 이름 + 날짜/시간
  → 스텝 2: 장소 선택 (지도 검색)
  → 스텝 3: 참여자 선택 (카카오톡 단톡방 초대 스타일)
  → 스텝 4: 확인 및 생성 (이동수단 + 출발지 선택)
```

- 상단에 진행률 바 표시 (Odiya-700 컬러)
- 스와이프 백으로 이전 스텝 (입력 값 유지)
- 마지막 스텝에서 전체 요약 확인 후 생성
- 생성 완료: Alert("약속 생성 완료") → dismiss

#### Step 3 참여자 선택 (카카오톡 스타일)

```
┌──────────────────────────┐
│ 🔍 친구 검색              │
├──────────────────────────┤
│ [👤민지 ✕] [👤서준 ✕]    │  ← 선택칩 (가로 스크롤)
├──────────────────────────┤
│ 👤 이하늘    ●친구        │  ← 탭→칩 추가 (.accepted만)
│ 👤 정우진    ●가족        │
└──────────────────────────┘
```

- 검색바로 친구 필터링
- 선택 시 상단에 칩 추가 (프로필 이미지 + 닉네임 + ✕)
- `.accepted` 상태 친구만 표시

#### Step 4 출발지

```
출발지
┌──────────────────────────┐
│ 🏠 집                  ✓ │  ← 등록된 장소 카드
│   서울 강남구 역삼동      │
├──────────────────────────┤
│ 🏢 회사                  │
├──────────────────────────┤
│ 🔍 다른 장소에서 출발     │  ← 지도 검색 시트 열기
├──────────────────────────┤
│ 🕐 나중에 지정            │  ← departurePlace = nil
└──────────────────────────┘
```

- 등록된 장소 카드에서 선택
- "다른 장소에서 출발" → DeparturePlaceSearchView 시트
- "나중에 지정" → departurePlace를 nil로 (Optional)

### 출발지 검색 시트

- 장소명/주소 검색
- 검색 결과 선택 → 출발지로 지정
- "이 장소를 출발지로 저장" 체크박스 (설정에도 등록)

### Alert 패턴 (토스트 제거)

| 상황 | 방식 |
|------|------|
| 친구 끊기, 탈퇴, 로그아웃, 출발지 삭제 | `.alert` + [취소] [확인(destructive)] |
| 요청 완료, 약속 생성 완료 | `.alert` + [확인] (정보성) |
| 기존 토스트 (2초 자동) | **제거** — 모두 Alert로 대체 |

### 로딩 상태

| 상황 | 처리 |
|------|------|
| 목록·카드 로딩 | ProgressView (시스템 스피너) |
| 버튼 액션 중 | 버튼 내 ProgressView + 비활성화 |
| 지도 로딩 | 스켈레톤 placeholder |

### 빈 상태 (Empty State)

- ContentUnavailableView 활용 (iOS 17+)
- 아이콘 + 안내 문구 + CTA 버튼

### 액션 피드백

- 성공/정보: `.alert` + [확인] 버튼
- 확인 필요 (삭제, 로그아웃 등): `.alert` + [취소] [확인(destructive)]
- 실패: 인라인 에러 메시지
- 로딩: ProgressView

## 주요 화면 UX 동선

### 약속 생성

```
약속 탭 toolbar [+]
  → 스텝 1: 이름 + 날짜/시간
  → 스텝 2: 장소 검색·선택
  → 스텝 3: 참여자 선택 (카카오톡 스타일 칩)
  → 스텝 4: 확인 (이동수단 + 출발지 카드/검색/"나중에 지정")
  → [약속 만들기] → Alert("약속 생성 완료") → dismiss
```

### 재촉하기

```
내 약속 → 임박한 약속 카드
  → [재촉하기] 버튼 탭
  → Haptic + bounce 애니메이션
  → Nudge 푸시 전송
  → 체크마크 애니메이션 + 쿨다운 시작
```

### 출발 알림 수신

```
푸시 알림 수신: "지금 출발하면 딱 맞아요!"
  → 알림 탭 → 약속 상세 화면
  → [길찾기] → 외부 지도 앱 열기 (카카오맵 > 네이버맵 > 애플맵)
```
