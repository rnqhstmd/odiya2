## 디자인 원칙

- **차분한 프리미엄 (v2)** — 토스 + Linear 감성, 에어리한 여백, 한 화면 한 메시지
- **직관적** — 설명 없이도 약속 생성·출발 알림·재촉하기 흐름을 파악 가능
- **iOS 네이티브** — HIG(Human Interface Guidelines) 준수, SwiftUI 기본 컴포넌트 활용
- **태그 = 개인화 액센트** — 친구 태그 컬러가 해당 약속의 카드·캘린더 도트·상세 액센트로 전파
- **시그니처 HERO** — 출발 카운트다운을 크고 극적으로, 재촉 CTA 는 별도 산호 액센트 + glow
- **다크모드 전체 지원** — SwiftUI `colorScheme` 기반, 토큰만으로 자동 전환

### 디자인 개선 사항 (v2)

프로토타입 v1 이후 적용된 개선:

- **아바타**: 단색 원 → 그라데이션 배경 + 한글 이니셜 텍스트
- **그림자**: 카드에 `#5B3A8C1A` 또는 `#0000001A` 기반 소프트 섀도우
- **지도**: 빈 회색 → 그라데이션 패턴 + 퍼플 핀 마커 (그림자 포함)
- **카운트다운**: 약속 상세 상단에 핑크 그라데이션 배너 (`#D94F8A` → `#E87AAE`)
- **알림 아이콘**: 유형별 그라데이션 색상 (친구요청=퍼플, 확정=초록, 출발=핑크, 수락=스카이)
- **설정**: 메뉴 서브텍스트, 앱 버전 표시 추가
- **친구 추가**: QR 코드 섹션, "또는" 구분선 추가
- **로그인**: Apple 로그인 버튼, 이용약관 텍스트, 그라데이션 배경 추가
- **태그 칩**: 카운트 뱃지 표시 (예: "친구 (3)")
- **친구 행**: "공통 약속 N개" 서브 정보 추가
- **이동수단**: 각 옵션에 예상 시간 표시
- **입력 필드**: 포커스 상태 표현 (보라 테두리 + 흰 배경)

### 태그 = 개인화 액센트

친구 태그 8색(lavender/rose/sky/mint/amber/coral/olive/slate)의 `solid` 가 해당 친구·약속의 카드 좌측바, 아바타 그라데이션, 캘린더 도트, 상세 화면 액센트에 **일관되게 전파**된다. 색상값은 [`v2-design-renewal.md` § 태그 팔레트](v2-design-renewal.md#태그-팔레트-친구-태그--앱-개인화-액센트) 참조.

## 타이포그래피 (v2)

- **한글**: Pretendard Variable — 앱 기본 폰트
- **영문·숫자**: SF Pro Text / SF Pro Display (iOS 시스템) — 숫자·영문 단독 시 자동 적용
- **숫자 정렬**: 시간·카운트다운·거리·요금 등 모든 tabular 한 숫자에 `.monospacedDigit()` 필수

| 용도 | 크기 | 굵기 | letterSpacing | 비고 |
|------|------|------|---------------|------|
| Nav 대형 타이틀 | 28 | 800 | -0.8 | 홈/약속/친구 상단 |
| 섹션 헤더 | 20 | 700 | -0.5 | |
| HERO 카운트다운 숫자 | 72~84 | 800 | -2 | `.monospacedDigit()` 필수 |
| 버튼 (lg) | 17 | 700 | -0.3 | |
| Body | 15~17 | 400~500 | -0.2 | |
| 라벨/캡션 | 12~13 | 600 | -0.2 | |

> Pretendard 는 이미 앱 번들에 임베드하거나 런타임 다운로드. SwiftUI 는 `.custom("Pretendard-..", size:)` + `.monospacedDigit()` 조합으로 렌더. Dynamic Type 지원을 위해 상대 크기(`.body`, `.headline` 등)와의 매핑도 `OdiyaTypography.swift` 에서 함께 정의.

## 주요 화면 레이아웃

### 로그인 (v2)

- 배경: 라이트 = `bg` (`#FAFAFC`) 단색 + 상단 은은한 보라 그라데이션 오라 / 다크 = `dbg` (`#0B0B11`)
- 중앙 상단: `ODIYA` 워드마크 (대형 타이틀 웨이트 800) + "약속 시간, 함께 지켜요" 서브 카피
- 중앙: 보라 그라데이션 원형 로고 (`p700` → `p500`) + map-pin
- 하단: **카카오 로그인 버튼만** (`kakao #FEE500`, 풀블리드, `r=lg`, h=56) — Apple 로그인은 제거됨 (카카오 단일 연동)
- 최하단: 이용약관 및 개인정보 처리방침 동의 안내 텍스트
- 다크: 전체 시맨틱 토큰만 스위치 (카카오 버튼 노란색은 브랜드 고정)

### 내 약속 (메인)

- 상단: "내 약속" 타이틀 + 프로필 아이콘
- 세그먼트: [다가오는 약속] [지난 약속]
- **임박한 약속 카드 (강조)**
  - 배경: Odiya-100 (`#F0E6F7`)
  - 약속명, 장소, 시간, 참여자 프로필 스택
  - 이동수단 아이콘 + 소요시간
  - 출발 카운트다운 타이머 (실시간)
  - 재촉 버튼 (Nudge 컬러 `#D94F8A`, 30분 전 활성화)
- 일반 약속 카드: 컴팩트 (약속명, 장소, 시간, 상태 배지)
- 빈 상태: 아이콘 + 안내 문구 + "약속 만들기" CTA 버튼

### 캘린더 (v2 — Variant A · 리치 프리뷰)

- 상단: 월/연 Nav 대형 타이틀 + [◀] [▶] 월 이동 · [오늘] 액션 버튼
- 월간 뷰 단독 (v2 에선 **월/주 토글 제거** — 주간 타임라인은 약속 리스트 섹션으로 흡수)
- 그리드: 요일 헤더(월~일) + 날짜 셀 + 약속 있는 날짜에 태그 색상 도트 최대 3개 (초과 시 `+N`)
- 선택된 날짜: `p100` 배경 + `p700` 텍스트 / 다크는 `p900` + `p300`
- 하단: 선택 날짜 약속 리스트 — 풀 카드 (태그 좌측 컬러바 + 시간 + 장소 + 참여자 스택)
- 빈 날짜 탭 → 해당 날짜로 약속 생성 진입

### 친구 목록

- 상단: "친구" 타이틀 + toolbar [+] 🔔 👤
- 검색 바
- 태그 필터 칩: `[●전체] [●친구 (3)] [●연인 (1)] [●가족 (1)]` — 카운트 뱃지 포함
- 친구 행: 그라데이션 이니셜 아바타 + 닉네임 + 태그 도트 + "공통 약속 N개" 서브텍스트
- 컨텍스트 메뉴 (`···`): 태그 변경, 친구 끊기 (=차단)

### 설정

- 상단: 그라데이션 이니셜 프로필 아바타 + 닉네임 + "프로필 편집" 버튼
- 그룹1: 출발지 관리 (서브: "3개 저장됨"), 태그 관리 (서브: "5개 태그")
- 그룹2: 알림 설정, 개인정보 처리방침
- 로그아웃 (빨강 강조) / 회원 탈퇴 (회색 텍스트)
- 최하단: 앱 버전 표시 ("오디야 v1.0.0")

### 알림 목록 (🔔 시트)

- 푸시 알림 기록 목록
- 친구 요청: 수락/거절 버튼 인라인
- 약속 초대: 탭 → 약속 상세
- 출발 알림, 재촉 알림
- 읽지 않은 알림 강조 (Odiya-50 배경)

### 내 정보/설정 (👤 시트)

- 프로필 이미지 + 닉네임
- 내 프로필 → ProfileView
- 설정 → SettingsView
- 로그아웃 (Alert 확인/취소)

## UX 패턴

### 재촉하기 UX (v2 · 옵션 B)

약속 상세 하단 [재촉하기] 버튼 → **재촉 시트** 오픈 (옵션 B: 스펙 충실)

- **시트 내용**: "아직 출발 안 한 친구" 체크리스트 (도착/출발 완료 친구는 disabled) + 5분 쿨다운 안내 문구
- **메시지 선택지 없음** — 푸시 문구는 서버 고정 (`{이름}이(가) 출발하래요!`). v1 단계에서 임시로 넣었던 "어디야?/출발했어?" 선택은 **제거**
- CTA 라벨: "N명 재촉하기" (선택 인원 수 반영)
- **Haptic Feedback**: CTA 탭 시 `.impact(.medium)` 진동
- **Bounce 애니메이션**: scale down → up 바운스 효과
- 전송 성공: 체크마크 애니메이션 → 시트 dismiss → 상세 화면 재촉 버튼이 쿨다운 상태로 전환
- 쿨다운 중: 버튼 비활성화 + 원형 프로그레스로 남은 시간 표시
- 버튼 컬러: `accent #FF5E7A` + `shadow.glow` (라이트) / 다크는 보더 강조

> v1 `Nudge #D94F8A` 는 v2 에서 `accent #FF5E7A` (산호/핫핑크 쪽) 로 이동. `OdiyaColors.nudge` → `OdiyaColors.accent` 로 이름 변경 권장.

### 약속 생성 — 스텝 위저드

입력 항목이 많으므로 단계별로 나눈다.

```
스텝 1: 약속 이름 + 날짜/시간
  → 스텝 2: 장소 선택 (지도 검색)
  → 스텝 3: 참여자 선택 (카카오톡 단톡방 초대 스타일)
  → 스텝 4: 확인 및 생성 (이동수단 + 출발지 선택)
```

- 상단에 진행률 바 표시 (Odiya-700 컬러)
- 스와이프 백으로 이전 스텝 (입력 값 유지)
- 마지막 스텝에서 전체 요약 확인 후 생성
- 생성 완료: Alert("약속 생성 완료") → dismiss

#### Step 3 참여자 선택 (카카오톡 스타일)

```
┌──────────────────────────┐
│ 🔍 친구 검색              │
├──────────────────────────┤
│ [👤민지 ✕] [👤서준 ✕]    │  ← 선택칩 (가로 스크롤)
├──────────────────────────┤
│ 👤 이하늘    ●친구        │  ← 탭→칩 추가 (.accepted만)
│ 👤 정우진    ●가족        │
└──────────────────────────┘
```

- 검색바로 친구 필터링
- 선택 시 상단에 칩 추가 (프로필 이미지 + 닉네임 + ✕)
- `.accepted` 상태 친구만 표시

#### Step 4 출발지

```
출발지
┌──────────────────────────┐
│ 🏠 집                  ✓ │  ← 등록된 장소 카드
│   서울 강남구 역삼동      │
├──────────────────────────┤
│ 🏢 회사                  │
├──────────────────────────┤
│ 🔍 다른 장소에서 출발     │  ← 지도 검색 시트 열기
├──────────────────────────┤
│ 🕐 나중에 지정            │  ← departurePlace = nil
└──────────────────────────┘
```

- 등록된 장소 카드에서 선택
- "다른 장소에서 출발" → DeparturePlaceSearchView 시트
- "나중에 지정" → departurePlace를 nil로 (Optional)

### 출발지 검색 시트

- 장소명/주소 검색
- 검색 결과 선택 → 출발지로 지정
- "이 장소를 출발지로 저장" 체크박스 (설정에도 등록)

### Alert 패턴 (토스트 제거)

| 상황 | 방식 |
|------|------|
| 친구 끊기, 탈퇴, 로그아웃, 출발지 삭제 | `.alert` + [취소] [확인(destructive)] |
| 요청 완료, 약속 생성 완료 | `.alert` + [확인] (정보성) |
| 기존 토스트 (2초 자동) | **제거** — 모두 Alert로 대체 |

### 로딩 상태

| 상황 | 처리 |
|------|------|
| 목록·카드 로딩 | ProgressView (시스템 스피너) |
| 버튼 액션 중 | 버튼 내 ProgressView + 비활성화 |
| 지도 로딩 | 스켈레톤 placeholder |

### 빈 상태 (Empty State)

- ContentUnavailableView 활용 (iOS 17+)
- 아이콘 + 안내 문구 + CTA 버튼

### 액션 피드백

- 성공/정보: `.alert` + [확인] 버튼
- 확인 필요 (삭제, 로그아웃 등): `.alert` + [취소] [확인(destructive)]
- 실패: 인라인 에러 메시지
- 로딩: ProgressView

## 주요 화면 UX 동선

### 약속 생성

```
약속 탭 toolbar [+]
  → 스텝 1: 이름 + 날짜/시간
  → 스텝 2: 장소 검색·선택
  → 스텝 3: 참여자 선택 (카카오톡 스타일 칩)
  → 스텝 4: 확인 (이동수단 + 출발지 카드/검색/"나중에 지정")
  → [약속 만들기] → Alert("약속 생성 완료") → dismiss
```

### 재촉하기

```
내 약속 → 임박한 약속 카드
  → [재촉하기] 버튼 탭
  → Haptic + bounce 애니메이션
  → Nudge 푸시 전송
  → 체크마크 애니메이션 + 쿨다운 시작
```

### 출발 알림 수신

```
푸시 알림 수신: "지금 출발하면 딱 맞아요!"
  → 알림 탭 → 약속 상세 화면
  → [길찾기] → 외부 지도 앱 열기 (카카오맵 > 네이버맵 > 애플맵)
```
