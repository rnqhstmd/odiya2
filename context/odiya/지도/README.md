## 지도 렌더링

- 카카오맵 iOS SDK로 네이티브 지도 표시
- 약속 장소에 핀 마커 표시
- 약속 상세 화면에서 지도 노출

---

## 장소 검색

- 사용자가 키워드 입력 → 백엔드에서 카카오 로컬 API 호출
- 검색 결과를 리스트로 표시 (장소명, 주소, 카테고리)
- 장소 선택 시 좌표·주소 저장

---

## 외부 앱 연결

약속 상세에서 "길찾기" 탭 시 외부 지도 앱으로 이동한다.

### 우선순위

1. **카카오맵** — URL Scheme으로 연결
2. **네이버맵** — 카카오맵 미설치 시 폴백
3. **애플맵** — 둘 다 미설치 시 기본 폴백

## 백엔드 API

> 공통: 모든 응답은 `ApiResponse<T>` 래퍼. 인증: `Bearer {accessToken}` 헤더

### 장소 검색 API — PlaceV1Controller (✅ 구현 완료)

#### 1. 장소 검색 (카카오 로컬 API 프록시)

| 항목 | 값 |
|------|-----|
| Method | `GET` |
| URL | `/api/v1/places/search?keyword={keyword}&page={page}&size={size}` |
| iOS 화면 | Step2PlaceView (약속 장소), DeparturePlaceSearchView (출발지) |

**Query Parameters:**

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| keyword | String | O | 검색어 (장소명/주소) |
| page | Integer | X | 페이지 번호 (기본 1) |
| size | Integer | X | 페이지 크기 (기본 15) |

**Response Body:**

| 필드 | 타입 | 설명 |
|------|------|------|
| places | List&lt;PlaceResponse&gt; | 검색 결과 |
| hasNext | Boolean | 다음 페이지 존재 |

**PlaceResponse:**

| 필드 | 타입 | 설명 |
|------|------|------|
| kakaoPlaceId | String | 카카오 장소 ID |
| name | String | 장소명 |
| address | String | 지번 주소 |
| roadAddress | String | 도로명 주소 |
| category | String | 카테고리 (음식점, 카페 등) |
| latitude | Double | 위도 |
| longitude | Double | 경도 |

**서버 내부 동작:** 카카오 로컬 API (`GET https://dapi.kakao.com/v2/local/search/keyword.json`) 호출 → 결과 변환. 헤더: `Authorization: KakaoAK {REST_API_KEY}`

### 이동시간 계산 (내부 서비스 — Controller 없음)

별도 API 엔드포인트 없이, 약속 관련 API의 부수 효과로 실행된다.

| 이동수단 | 외부 API | 호출 URL |
|----------|---------|---------|
| CAR_PARKING / CAR_PICKUP | 카카오모빌리티 | `GET https://apis-navi.kakaomobility.com/v1/directions?origin={lng},{lat}&destination={lng},{lat}` |
| TRANSIT | ODsay | `GET https://api.odsay.com/v1/api/searchPubTransPathT?SX={lng}&SY={lat}&EX={lng}&EY={lat}&apiKey={key}` |
| WALKING | 직선거리 계산 | API 미사용 (Haversine 공식 / 분속 80m) |
