# odiya (어디야) 용어 사전

| 용어 | 설명 |
|------|------|
| 약속 | 특정 장소·시간에 만나는 이벤트. 앱의 핵심 단위 |
| 호스트 | 약속을 생성한 사람. 수정·취소·추가 초대 권한 보유 |
| 참여자 | 약속에 초대되어 수락한 사람 (호스트 포함) |
| 출발 알림 | 역산 공식으로 계산된 출발 시각에 보내는 푸시 알림 |
| 역산 공식 | `출발알림시각 = 약속시간 - API소요시간 - 주차버퍼(해당시) - 여유시간` |
| 이동시간 | 출발지에서 약속 장소까지 예상 소요 시간 |
| 이동수단 | CAR_PARKING / CAR_PICKUP / TRANSIT / WALKING 의 4종. 이동시간 계산에 사용 |
| 주차 버퍼 | 자동차(주차) 시 주차 탐색 + 주차 + 도보 시간을 위한 여유 (기본 10분, 사용자 조절 가능) |
| 여유 시간 | 모든 이동수단에 공통 적용되는 출발 전 여유 시간 (기본 5분, 사용자 조절 가능) |
| 재촉하기 (Nudge) | 약속 30분 전부터 활성화되는 "출발해!" 푸시 알림 전송 기능 |
| 쿨다운 | 재촉하기 남용 방지를 위한 최소 대기 시간 (동일 대상 5분) |
| 출발지 | 사용자가 등록한 출발 위치. 이동시간 계산의 기준점 |
| PENDING | 약속 상태. 초대 발송 후 참여자가 아직 수락하지 않은 상태 |
| CONFIRMED | 약속 상태. 참여자가 수락하여 약속이 확정된 상태 |
| COMPLETED | 약속 상태. 약속 시간이 지나 완료된 상태 |
| CANCELLED | 약속 상태. 호스트가 취소한 상태 |
| 관계 태그 | 친구에게 부여하는 분류 라벨 (친구/연인/가족/기타 + 사용자 정의) |
| 태그 색상 | 각 관계 태그에 지정하는 커스텀 색상. 캘린더 도트에 반영 |
| 친구 요청 | 카카오톡 1:1 톡방에서 친구 요청 링크를 보내는 친구 추가 요청 |
| 딥링크 | 앱 내 특정 화면으로 바로 이동하는 링크. 친구 요청·약속 공유 메시지에 포함 |
| JWT | JSON Web Token. 인증에 사용 (access 1시간 + refresh 30일) |
| APNs | Apple Push Notification service. iOS 푸시 알림 전송 채널 |
| 카카오모빌리티 API | 자동차 이동시간 계산에 사용. 실시간 교통 반영. 일 1만건 무료 |
| ODsay API | 대중교통 이동시간 계산에 사용. door-to-door. 일 1,000건 무료 (6개월) |
| 카카오맵 iOS SDK | iOS 지도 렌더링에 사용. 일 300,000건 무료 |
| 카카오 로컬 API | 장소 검색에 사용. 일 100,000건 무료 |
| 카운트다운 | 메인 화면에서 출발까지 남은 시간을 실시간 표시하는 UI |
| 월간 뷰 | 캘린더 월간 보기. 약속이 있는 날짜에 태그 색상 도트 표시 |
| 주간 뷰 | 캘린더 주간 보기. 타임라인 형태로 약속 블록 표시 |
| S3 Presigned URL | AWS S3가 발급하는 시간 제한 업로드 URL. iOS 앱이 백엔드 경유 없이 직접 S3에 PUT 업로드. 만료 10분 |
| QR 친구 추가 딥링크 | `odiya://friend?userId={id}` 형식. 내 QR 생성 → 상대가 스캔 → 기존 친구 요청 API 재사용 |
| 디자인 v2 | 2026-04-22 전면 리뉴얼된 iOS 디자인. 토스+Linear 감성 · 깊은 보라 11단 + 모던 그레이 + 산호 액센트 · Pretendard+SF Pro · 전체 다크모드. 상세: [`디자인-UX/v2-design-renewal.md`](디자인-UX/v2-design-renewal.md) |
| 산호 액센트 | v2 재촉/긴급 전용 컬러 `#FF5E7A`. v1 의 Nudge `#D94F8A` 를 대체 |
| 태그 개인화 | 친구에게 부여된 태그 색이 해당 친구·약속의 카드/캘린더 도트/아바타/상세 화면 액센트로 **일관되게 전파**되는 v2 패턴 |
| tabular-nums | 숫자 너비를 고정하여 카운트다운·시간·거리 정렬을 맞추는 폰트 feature. SwiftUI `.monospacedDigit()` |
| 글래스 카드 | 약속 상세 v2 (Variant B) 에서 지도 위에 띄우는 반투명 카드. SwiftUI `.ultraThinMaterial` |
| Claude Design | `claude.ai/design` 의 디자인 아티팩트 도구. 프로토타입 HTML/CSS/JS 번들을 내보내 코딩 에이전트가 구현하도록 전달 |
