# 캘린더

- 작성일: 2026-03-03
- 수정일: 2026-03-04 (백엔드 API 매핑 추가)
- 관련 레포: odiya-ios, odiya-api

---

## 개요

자체 캘린더로 약속 날짜·시간·장소를 한눈에 확인한다. iOS 시스템 캘린더와는 연동하지 않는다.

---

## 월간 뷰

- 한 달 단위 캘린더 그리드
- 약속이 있는 날짜에 **도트 표시**
- 도트 색상은 해당 약속 참여자의 **관계 태그 색상** 반영
- 하루에 여러 약속이 있으면 도트 여러 개 표시 (최대 3개, 초과 시 `+N`)
- 오늘 날짜 자동 강조

---

## 주간 뷰

- 한 주 단위 타임라인 형태
- 약속을 **시간 블록**으로 표시 (시작시간 기준 배치)
- 블록에 약속명 + 장소명 표시
- 블록 색상은 관계 태그 색상 반영

---

## 날짜 선택

- 월간 뷰에서 날짜 탭 → 하단에 해당 날의 **약속 리스트** 표시
- 리스트 항목: 약속명, 시간, 장소
- 약속 카드 탭 → **약속 상세** 화면으로 이동

---

## 약속 생성 진입

- **빈 날짜** 탭 → 해당 날짜가 기본값으로 설정된 약속 생성 화면 진입
- 약속이 있는 날짜에서도 "+" 버튼으로 추가 생성 가능

---

## 내비게이션

- **스와이프**로 월/주 이동 (좌: 이전, 우: 다음)
- 상단 월/주 전환 토글
- "오늘" 버튼으로 현재 날짜로 즉시 복귀

---

## 백엔드 API 매핑

캘린더 전용 API는 없다. [약속-관리](../약속-관리/) API를 사용한다.

| iOS 동작 | 호출 API | 설명 |
|----------|---------|------|
| 월간/주간 뷰 진입 | `GET /api/v1/appointments/calendar?year=&month=` | 해당 월의 약속 요약 (날짜별 도트 표시용) |
| 날짜 탭 → 약속 리스트 | 위 응답에서 로컬 필터링 | 해당 날짜의 appointments 배열 |
| 약속 카드 탭 → 상세 | `GET /api/v1/appointments/{id}` | 약속 상세 조회 |
| 빈 날짜 탭 → 약속 생성 | `POST /api/v1/appointments` | 해당 날짜를 기본값으로 약속 생성 |

**캘린더 응답 형식** — `GET /api/v1/appointments/calendar`:

| 필드 | 타입 | 설명 |
|------|------|------|
| date | String | 날짜 (yyyy-MM-dd) |
| appointments[].id | Long | 약속 ID |
| appointments[].name | String | 약속 이름 |
| appointments[].dateTime | String | 약속 일시 (ISO-8601) |
| appointments[].placeName | String | 장소명 |
| appointments[].tagColor | String | 대표 태그 색상 hex (도트 표시용) |

상세: [약속-관리 API](../약속-관리/)
